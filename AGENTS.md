# trygg

Effect-native UI framework with JSX support and fine-grained reactivity.

Package manager: `bun`

Repo commands:

- `bun run build`
- `bun run typecheck`
- `bun run test`
- `bun run check`
- `bun run examples`

Code exploration:

- If code is reachable locally, explore it with local code search and file-reading tools.
- If code is not reachable locally, use `opensrc`.
- Avoid `webfetch` unless there is no viable code source.
