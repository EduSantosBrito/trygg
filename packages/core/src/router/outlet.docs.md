# Outlet

## When to use

Use `Outlet` to render the matched route tree at the app root or inside layouts that need nested child content.

## Behavior

`Outlet` resolves the active manifest, matches the current path, runs middleware, chooses nearest boundaries, applies render and scroll strategy resolution, and stacks layouts from root to leaf around the matched component.
